# Next.js App Router Starter

This is a Next.js application using the App Router.

## Features

- ✅ React 19 with App Router
- ✅ TypeScript
- ✅ ESLint with Next.js configuration
- ✅ Tailwind CSS
- ✅ Next.js themes support
- ✅ Toast notifications (sonner)
- ✅ Radix UI components
- ✅ Shadcn/ui components
- ✅ Lucide React icons
- ✅ JWT authentication utilities
- ✅ Environment variables support

## Getting Started

Install the project dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

For production deployments, you can use Vercel, Netlify, or any other hosting service.

## Scripts

- `npm run dev` - Run the development server
- `npm run build` - Build the application for production
- `npm run start` - Start the production server
- `npm run lint` - Run ESLint to check code quality

## Environment Variables

Add environment variables to `.env` file (see `.env.example` for reference)
